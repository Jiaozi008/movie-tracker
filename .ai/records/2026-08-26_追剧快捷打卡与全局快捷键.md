# 变更记录: 追剧快捷打卡与全局快捷键 (P0)

- **日期**: 2026-08-26 23:03:00
- **执行阶段**: 阶段 1 (P0)
- **版本**: v1.1.0

## 1. 变更背景与需求
- 用户日常追剧时，每看一集都需要点开编辑表单修改集数，摩擦过大。
- 用户提出追剧一键 `+1` 打卡，且希望自动记录具体的打卡时间与观看日期。
- 桌面端缺乏全局快捷键支持（聚焦搜索、新建记录、退出弹窗）。

## 2. 详细技术方案
1. **数据模型扩展 (`types.ts`)**:
   - 增加 `EpisodeWatchLog` 接口 (`{ episode: number; date: number; note?: string }`)。
   - 在 `Movie` 接口中扩展 `watchHistory?: EpisodeWatchLog[]`。
2. **逻辑核心与时间处理 (`utils/episodeUtils.ts`)**:
   - `calculateEpisodeUpdate`: 纯函数计算 +1 / -1，更新当前集数、追加时间戳日志流水、刷新 `lastUpdated` 并智能判断完结状态。
   - `formatRelativeWatchDate`: 相对时间友好格式化（刚刚、X分钟前、今天 22:58、8月26日）。
3. **交互与 UI 呈现 (`components/MovieCard.tsx`)**:
   - 在电视剧卡片正面进度条右侧提供 `+1` / `-1` 快捷胶囊按钮。
   - 展示最近打卡时间 Badge。
   - 在详情折叠区生成打卡流水足迹。
4. **全局快捷键 Hook (`hooks/useKeyboardShortcuts.ts`)**:
   - 监听 `Ctrl/Cmd + K` 聚焦搜索框。
   - 监听 `N` 快速打开新建记录（智能过滤正在输入的元素）。
   - 监听 `Esc` 关闭所有活动 Modal。
5. **单元测试 (`tests/quickEpisodeUpdate.test.ts`)**:
   - 9 个独立测试用例全量验证。
