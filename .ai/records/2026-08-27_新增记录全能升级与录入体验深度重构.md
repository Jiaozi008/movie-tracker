# 2026-08-27 「新增记录」表单全能升级与录入体验深度重构

## 1. 任务背景与目标
针对用户在「新增记录」表单中的高频痛点（字段繁多视觉压力大、评分颗粒度不够细、从豆瓣/外部复制信息输入繁琐、截图无法直接粘贴、误触导致填写内容丢失、打卡选日期繁琐等），全面实施 A+B+C 组合升级方案：
1. **表单渐进式分层折叠**：区分高频核心字段与进阶元数据。
2. **0.5 半星精细评分体系**：支持 10 分制双模评级联动。
3. **剪贴板智能解析**：一键识别书名号片名、豆瓣/IMDb 链接、年份与季数。
4. **Ctrl+V 截图直接粘贴海报**：剪贴板图片自动压缩为 Base64/WebP 填入封面。
5. **快捷日期胶囊**：「今天」「昨天」「前天」一键快速选定。
6. **草稿箱自动暂存与恢复**：防抖暂存至 `sessionStorage`，防止意外关闭丢失数据。

---

## 2. 核心架构与代码变更

### 2.1 0.5 半星评分组件升级 (`components/StarRating.tsx`)
- 基于分层裁剪（Overlay Clip）方案，实现 0%、50%、100% 精准星级渲染。
- 将每个星划分为左右两个可点击交互区域（左半区 `+0.5`，右半区 `+1.0`），桌面端 hover 与移动端 touch 完美兼容。
- 允许再次点击清空评分（`allowClear`）。

### 2.2 TMDB 电视剧智能分季选择与单季精细化录入 (`services/tmdbService.ts` & `components/TmdbSearchModal.tsx`)
- 从 TMDB API `/tv/{id}` 的 `d.seasons` 数组中解析各季元数据（季号 `season_number`、单季集数 `episode_count`、首播年份、单季专属海报与简介）。
- 当用户在 TMDB 搜索选中电视剧时，展示**分季选择面板**：
  - 选项 1：**全剧汇总**（汇总全 X 季，共 Y 集，首季年份与总海报）。
  - 选项 2..N：**各季独立选项**（如「第 4 季」自动填充 2022 年、9 集与第 4 季专属海报），彻底解决多季混淆问题。

### 2.3 TMDB 备选海报库海选与一键切换 (`services/tmdbService.ts` & `components/MovieForm.tsx`)
- 在 TMDB API 请求中附加 `images` 扩展与中文/英文语言过滤，拉取前 8 张精选官方海报。
- 表单海报区以平滑滚动滑轨展示备选海报，支持点击任意一张秒级异步下载并替换封面。

### 2.4 重温多刷时间流水与短评一键复制 (`types.ts`, `MovieForm.tsx` & `MovieCard.tsx`)
- 扩展 `Movie.rewatchHistory: RewatchLog[]`，记录历次重温日期、评分与阶段短评。
- 卡片展开详情中提供「重温足迹时间轴」与「📋 复制短评」便捷操作。

### 2.3 剪贴板媒体智能解析引擎 (`utils/clipboardParser.ts`)
- 编写 `parseClipboardMediaText(raw)`：
  - 正则提取《片名》、豆瓣 `movie.douban.com/subject/...` 链接。
  - 自动识别并提取 `19xx/20xx` 年份、`S01/Season 1/第一季/第二季` 剧集季度。
  - 自动推导 `mediaType` 并清理多余杂质字符。
- 配套编写 `tests/clipboardParser.test.ts` 单元测试。

### 2.4 草稿暂存与偏移日期工具 (`hooks/useMovieForm.ts`)
- 提供 `saveFormDraft`、`loadFormDraft`、`clearFormDraft` 封装。
- 提供 `getTodayString` 与 `getOffsetDateString` 纯函数。

### 2.5 表单组件深度重构 (`components/MovieForm.tsx`)
- **渐进式折叠卡片**：将上映年份、国家地区、导演、时长、主演、观看平台、倍速播放收纳在可折叠区域，并实时展示「已填 X 项」胶囊。
- **草稿提示条**：若检测到有效草稿，顶部展示浮动胶囊「恢复 / 丢弃」。
- **快捷日期胶囊**：提供「今天 / 昨天 / 前天」快捷按钮。
- **全局图片粘贴监听**：`window.addEventListener('paste', ...)` 拦截剪贴板图片并调用 `resizeImage`。
- **评分评级联动**：打分时实时展示 `9.0分 · 神作` / `8.0分 · 推荐` / `6.0分 · 良作` 等徽章。
