## 1. 痛点与需求复盘

用户针对移动端「影人宇宙」提出了两项明确的体验改良要求：
1. **满屏无拉动条**：
   - 移动端原为 `max-h-[95vh] rounded-t-2xl`，未能满屏，在现代移动端显得上下割裂；
   - 分类 Tab 栏因为在末尾挤入了移动端的「校验全网 / 全量刷新」按钮，总宽度超出屏幕，渲染出一条灰黑色的浏览器原生横向拉动条（`< [====] >`），极不美观。
2. **探索全量档案精准定位**：
   - 用户在影人宇宙卡片中点击「探索生涯全量档案」或点击影人姓名跳转至主界面后，页面视口停留在此前滚动的位置或页面底部，需要用户手动往上滑才能看到该影人的全收录专栏。

## 2. 技术设计与解决方案

### 2.1 移动端原生级满屏沉浸式布局 (`components/PersonUniverseModal.tsx`)
- 外层容器采用 `fixed inset-0 z-50 flex items-center justify-center sm:p-4 md:p-6 bg-black/85 backdrop-blur-md`；
- 内层容器升级为 `w-full h-full sm:h-auto sm:max-w-5xl sm:max-h-[90vh] rounded-none sm:rounded-2xl`，移动端 100% 满屏无缝贴合，桌面端保持典雅视窗。

### 2.2 绝杀横向滚动条：4 等分网格 Tab + 校验按钮上移标题栏
- **校验/刷新按钮上移**：将原本嵌入在 Tab 行末尾的 `handleBatchSyncFilmography` 按钮移入顶部标题栏右侧，与关闭按钮 `✕` 紧凑并排呈现；
- **4 等分满屏网格**：Tab 栏重构为 `grid grid-cols-4 gap-1.5 w-full`，四个分类（全部、智库、进行中、大满贯）各占 25% 宽度，自适应任何移动端屏幕尺寸，彻底消除水平溢出与拉动条。

### 2.3 探索全量档案开头位置精准跳转 (`App.tsx`)
- 在 `App.tsx` 中为 `PersonCollectionBanner` 的外层容器声明 `ref={personBannerRef}`，并设置 `id="person-collection-section" className="scroll-mt-20 sm:scroll-mt-24"`；
- 在 `handleSelectPerson` 回调内增加平滑滚动触发机制：
  ```ts
  requestAnimationFrame(() => {
      setTimeout(() => {
          if (personBannerRef.current) {
              personBannerRef.current.scrollIntoView({ behavior: 'smooth', block: 'start' });
          } else if (librarySectionRef.current) {
              librarySectionRef.current.scrollIntoView({ behavior: 'smooth', block: 'start' });
          } else {
              window.scrollTo({ top: 0, behavior: 'smooth' });
          }
      }, 60);
  });
  ```
- 点击「探索生涯全量档案」关闭弹窗后，视口自动平滑定位至该影人专栏开头，视觉焦点清晰。
