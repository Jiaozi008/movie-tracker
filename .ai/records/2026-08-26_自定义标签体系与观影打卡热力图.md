# 2026-08-26 自定义标签体系与观影打卡热力图 (阶段 2 / v1.2.0)

## 1. 任务背景
在追剧快捷打卡与全局快捷键（阶段 1）交付后，继续执行用户提出的阶段 2 核心需求：
1. 为作品引入自定义标签体系 (Tags)，支持个性化打标、常用标签智能候选池、卡片展示与多维精准筛选。
2. 引入仿 GitHub 提交风格的 365 天观影打卡热力图 (Activity Heatmap)，无缝聚合电影观看与电视剧每集打卡流水，直观呈现年度活跃度与连续打卡天数。

## 2. 核心架构与实现变更

### 2.1 标签数据模型与交互
- **模型扩展**：在 `types.ts` 与 `hooks/useMovieForm.ts` 中扩展 `tags?: string[]` 字段。
- **表单录入与管理 (`components/MovieForm.tsx`)**：
  - 支持输入框回车、逗号快速添加标签；
  - 自动从现有作品库中提取已有标签构建常用标签池（Top 12），支持一键点选添加；
  - 标签以胶囊 Chip 徽章展示，支持一键移除。
- **卡片展示 (`components/MovieCard.tsx`)**：
  - 卡片正面展示前 3 个标签 Chip，超过展示 `+N`；
  - 卡片展开详情区展示完整标签列表。
- **全局筛选与检索 (`App.tsx`)**：
  - 顶部筛选栏新增「所有标签」下拉筛选维度；
  - 模糊搜索自动扩展包含 `movie.tags` 的多字段联搜。
- **数据兼容与迁移 (`utils/fileUtils.ts`)**：
  - CSV 导出新增「标签」列，支持 `;` 拼接导出与自动解析还原；
  - JSON 导入导出完整序列化 `tags` 数组。

### 2.2 观影打卡热力图 (`components/ActivityHeatmap.tsx`)
- **日历矩阵渲染**：
  - 52 周按星期对齐排列，支持「最近一年」与历史年份自由切换；
  - 基于活跃频次动态映射 5 级发光阶梯色彩（无记录、浅紫、明亮紫、洋红、琥珀橙金渐变）。
- **打卡流水聚合**：
  - 电视剧优先遍历 `watchHistory` 中的毫秒级时间戳，电影遍历 `addedAt` 时间戳；
  - 准确计算 4 大核心指标：**累计打卡次数**、**活跃天数**、**当前连续天数**、**最长连续天数**。
- **微交互与毛玻璃悬停气泡**：
  - 鼠标悬停或点击任意方格，弹出毛玻璃 Tooltip，清晰展示当日观看的所有电影与电视剧集数。
- **统计面板集成 (`components/Stats.tsx`)**：
  - 在统计面板顶部显著位置挂载热力图，与影视分布图表浑然一体。
