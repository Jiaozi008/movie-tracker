# 2026-09-01 卡片详情独立放大展开与网格防拉伸优化

## 1. 需求与问题背景
- **痛点分析**：在多列卡片网格布局（CSS Grid）中，用户点击任意卡片右下角「详情」时，原逻辑直接在卡片内部内联展开（高度由 ~400px 激增至 900px+）。由于 CSS Grid 默认特征 `align-items: stretch`，**整行中的所有其他卡片被强制拉长**，在另外三张卡片底部产生了大面积空白灰区。同时，展开的卡片受制于单列仅约 280px-300px 的狭窄宽度，长文本剧情简介、分段流水和追剧打卡足迹极度拥挤、体验不佳。
- **用户诉求**：修改成**单独展开**，并且能**放大该卡片**，让用户能更清晰舒适地看到内容，且**不用整行都展开**。

## 2. 解决方案与核心设计

### (1) 独立放大展开聚焦视窗 (`components/MovieCard.tsx`)
- 原内联折叠容器从普通流中剥离，通过 React 的 `createPortal` 挂载到 `document.body`；
- 采用电影级暗黑毛玻璃遮罩（`fixed inset-0 z-50 bg-black/80 backdrop-blur-md animate-in fade-in`）；
- 核心卡片容器设定为宽幅高保真大卡片（`max-w-2xl w-full max-h-[90vh] bg-slate-900 border border-slate-700/80 rounded-2xl shadow-2xl`），字体、间距、海报画幅均按大屏阅读舒适度全面升级。

### (2) 视窗功能与交互完整对齐
- **超大海报头图**：更宽广画幅、高清海报、类型/平台徽章、直接可用的操作快捷键（Markdown 笔记复制、海报生成、编辑、删除）以及右上角关闭按钮 `✕`；
- **状态与评分阵列**：完整展示追剧状态、良作/神作徽章、多刷火焰徽章、播放倍速（含实际折算观影时长）、TMDB 权威评分与交互星级；
- **经典台词 Callout**：加粗高亮金句展示；
- **追剧打卡快捷组件**：`-1` 与 `+1` 快速打卡功能在放大视窗内 100% 交互可用，支持实时查看最近打卡时间；
- **完整结构化数据**：导演与主演点击可穿透检索专栏、时长、平台、类型、全量标签 Chip；
- **大版面剧情简介**：长文本无截断、舒适行高、选中文本支持；
- **影评 / 追剧随笔**：一键复制随笔按钮，分层展示多段深度长评；
- **分段倍速流水时间轴**：宽屏双列网格结构清晰对比各集区间与倍速；
- **按天聚合追剧足迹**：多天打卡足迹完整列出；
- **重温足迹多刷时间轴**：完整展示各刷次心得与轨迹；
- **底部工具栏**：展示记录日期，右侧提供醒目的「收起卡片 ⌃」按钮。

### (3) 轻量交互与防干扰
- **快捷键**：按 `Escape` 键一秒收起；
- **点击遮罩关闭**：点击卡片外部背景即收起；
- **背景防穿透**：展开时自动设置 `document.body.style.overflow = 'hidden'`，收起时自动还原；
- **父级网格防御**：在 `App.tsx` 中为所有卡片 Grid 容器添加 `items-start`，彻底杜绝任何高度关联拉伸。
