# 2026-08-26 剧集集数统计与多季独立统计修复 (Debug / v1.4.2)

## 1. 问题现象与排查
- **现象**：追剧打卡时，剧集集数统计（`totalEpisodesWatched`）在特定情况下（如多季剧集、特定时间筛选模式）未发生实时动态更新。
- **根因分析**：
  1. **标题标准化过度剥离季度 (`utils/titleNormalizer.ts`)**：原算法中使用了 `.replace(/第[一二三四五六七八九十\d]+季/g, '').replace(/season\s*\d+/gi, '').replace(/\bs\d{1,2}\b/gi, '')`，导致多季剧集（如《庆余年 第一季》与《庆余年 第二季》或《石油天王 S1》与《石油天王 S2》）被强行归为同一组。在增量去重算法下，后一季的集数被前一季覆盖吞噬，导致点击 `+1` 时集数增量为 0。
  2. **周期统计集数算法未适配 `watchHistory`**：在按月/按年筛选时，统计函数未精准匹配所选时间区间的打卡流水日志，导致打卡后当前月度/年度统计未感知到集数增加。

## 2. 修复方案
1. **`utils/titleNormalizer.ts`**：
   - 移除季数剔除正则，仅剥离 `(电视剧)`、`[TV]` 等媒体类型括号，完整保留各季度（第一季、第二季、S1、S2 等）的独立性。
2. **`utils/statsCalculator.ts`**：
   - `calculateTotalEpisodes` 与 `calculateTvDuration` 新增 `timeFilter` 参数 (`TimeFilterOptions`)。
   - 当按月/按年筛选时，精确遍历 `watchHistory` 流水计算落入该区间的打卡次数与时长；无流水时平滑回退至传统算法。
3. **组件调用适配**：
   - `components/Stats.tsx` 与 `components/ReportShareModal.tsx` 全面传入 `timeFilter` 选项。
4. **自动化测试**：
   - `tests/statsCalculator.test.ts` 补充多季独立集数统计与按月精确统计测试，全量 74 个测试 100% PASS。
